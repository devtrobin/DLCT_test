# Ionic

## À quoi cela sert

Ionic est une bibliothèque de composants d'interface destinée aux applications mobiles et web. Elle fonctionne avec les technologies du Web et possède une intégration officielle pour Vue 3.

## Minimum à connaître

- Ionic fournit des composants, styles, interactions, gestes et conventions d'interface mobile.
- `@ionic/vue` permet d'employer ces composants dans Vue.
- Ionic s'occupe surtout de l'interface ; Capacitor fournit l'accès au conteneur et aux fonctions natives.
- Une application Ionic peut cibler le Web, iOS et Android avec une base de code commune.

## Pour ce projet

Ionic n'est pas demandé. Une application Vue web classique suffit pour le test, sauf décision explicite de démontrer une expérience mobile.
