# Capacitor

## À quoi cela sert

Capacitor est un runtime natif multiplateforme qui embarque une application web dans des projets iOS et Android et lui donne accès aux fonctions de l'appareil au moyen de plugins.

## Minimum à connaître

- Il peut être ajouté à une application JavaScript moderne existante.
- Il génère et synchronise des projets natifs Android et iOS.
- Ses plugins exposent notamment la caméra, la géolocalisation, les notifications et le stockage natif.
- Une compilation web doit être produite puis synchronisée vers les projets natifs.
- Le développement iOS ou Android implique aussi les outils natifs correspondants.

## Pour ce projet

Capacitor n'est pas nécessaire : le sujet demande un frontend Vue.js, pas une application mobile installable.
